# September 29 release

This release includes the shared hangar for all modes, simplified pilot controls,
animated lobby branding and exit, persistent Discord profile access, and a centered
game selector. It incorporates PR #4's Classic scoring, difficulty and move-to-start
changes, preserves existing 1v1 speed, and respawns Classic pilots near the death
location with enemy clearance. A fresh game starts in the bottom-right corner.

The source includes the additive hangar-capacity and shared-game-room migrations.
They were tested locally but were not applied remotely during this release because
database deployment credentials were unavailable. The client detects the missing
shared-room RPC and uses the existing room services. Switching multiplayer modes
while retaining the room code and roster therefore remains unavailable on that
backend. Ranked and Arcade remain marked Coming soon.

Validation: 73 game tests and the isolated PostgreSQL shared-room checks passed.
TypeScript and the production build passed for the included Classic changes.
The release merge preserves that tested source tree. Publication uses the separate
alien-force-classic assets repository; game source is integrated into origin/main.
